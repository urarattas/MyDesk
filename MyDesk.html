高级：自定义 STUN / TURN

每行一个地址。默认是国内实测可用的公共 STUN；不同运营商可达性不同，建议先点「检测可用性」。 用 EasyTier 组网时填虚拟网里的 STUN，例如 stun:10.144.1.1:3478（脚本在下方「网络救急」）。

发回后等待对方点击「完成连接」，无需再操作。

      网络救急：STUN / EasyTier可选
      

        

          双方都是对称型 NAT 时 WebRTC 打洞会失败。两条兜底路线：① 填 TURN（上方「高级」里加一行）；
          ② 用 EasyTier 组一个虚拟局域网，让 WebRTC 走虚拟网 IP。
        

        

          为什么还需要 STUN 脚本：Chrome 会把 host 候选隐藏成 xxx.local（mDNS），
          TUN 虚拟网一般转发不了这个组播。在虚拟网里跑一个 STUN，候选就会变成虚拟网 IP，直连成功率最高。
        

        

          
          

          

            
            
          

        

        

          
          

        

      

    


    
    

      使用说明
      

        
    
          
  1. 两台设备各打开同一份 HTML（直接拷文件过去即可，无需安装）。
    2. 
          
  2. A 点「创建邀请码」→ 复制 → 用任意聊天工具发给 B。
    3. 
          
  3. B 点「接受邀请」→ 粘贴邀请码 → 生成回执码 → 发回给 A。
    4. 
          
  4. A 粘贴回执码 → 点「完成连接」→ 双方显示「已连接 · P2P」。
    5. 
          
  5. 任一端点「共享屏幕」，另一端即可实时看到画面。
    6. 
          
  6. 编码可随时切换（自动 / H.264 / VP9 / AV1），即时生效，不用重新握手。
    7. 
          
  7. 要操作对方：被控端打开「允许对方控制我」，控制端打开「我可以控制对方」，然后点击画面接管键鼠。
    8. 
        

        

          网络：同局域网/同一 NAT 后可直连；跨网络靠 NAT 打洞，STUN 只用于发现公网地址，不转发任何数据。
          双方都是对称型 NAT 时无法直连——这是 P2P 的固有限制，除非自建 TURN 中继。
        

        

          安全：握手码就是凭证，谁拿到都能连；媒体为 DTLS-SRTP 端到端加密；控制权限默认关闭，
          需被控端显式授权，可随时撤销。
        

        

          限制：浏览器无法直接操作系统输入，真正的键鼠注入需要可选的本地桥接（上方「系统级操控」）。
